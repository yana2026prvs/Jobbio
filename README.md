# План виходу на ринок праці — трекер (UI/UX job search plan)

Односторінковий веб-застосунок (без білд-кроку, без залежностей) — трекер 13-тижневого плану пошуку роботи для UI/UX дизайнерки. Стилізований під мобільний застосунок (телефон-рамка), все — HTML/CSS/JS в одному файлі `index.html`.

## Що всередині

- **План (Plan)** — 13 тижнів, розбиті на фази (`Кейси`, `Сайт і CV`, `Пошук`), задачі з чекбоксами-статусами та розгортайкою "Деталі".
- **Відгуки на вакансії (Apps)** — трекер відгуків: статистика зверху (надіслано / відповіли / чекають), картки по кожній вакансії (компанія, посилання, опис, статус).
- **Навички (Skills)** — чекліст навичок, побудований на основі реального частотного аналізу 7 вакансій (UI/UX middle, mobile + SaaS), з позначенням найслабших місць.

Дані зберігаються в `localStorage` браузера (три ключі: `job-plan-statuses-v1`, `job-applications-v1`, `job-skills-v1`) — окремого бекенду немає.

## Як запустити локально

Файл самодостатній, бекенд не потрібен. Найпростіше:

```bash
# з корня проєкту
python3 -m http.server 8000
# або
npx serve .
```

і відкрити `http://localhost:8000` у браузері. Можна й просто відкрити `index.html` подвійним кліком.

## Технічний стек

Ванільний HTML/CSS/JavaScript, без фреймворків і збірки. Тема — примусово темна (CSS custom properties в `:root`). Дизайн-система: soft-gradient fintech UI (великі радіуси, скляні (glassmorphism) картки з backdrop-filter, лаймовий акцент для завершених станів).
